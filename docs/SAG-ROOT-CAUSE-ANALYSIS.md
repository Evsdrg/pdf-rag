# SAG 检索退化的逐层归因（2026-11-01）

> 本文主体保留修复前的归因现场，不是当前算法描述。后续修复与校准见
> [BENCHMARKS.md](BENCHMARKS.md) §4.10–§4.14：v2隔离5题，来源/词法/窗口/角色/参数槽已修改；
> 中间退化与最终剩余回归均保留。新候选和新窗口尚未获得真实模型重排验证。

## 1. 结论与可信边界

问题不应归因成“SAG 不适合”或“重排模型无效”。本仓库目前是有限的确定性实体桥，
不是 SAG 完整的事件抽取与动态超边引擎。本次复核发现两类相互叠加的问题：

1. **评测标注有语义错误及文件别名矛盾**，之前的覆盖分数不等于真实问题正确率。
2. **来源去重、词法、候选截断、固定窗口和页面惩罚有可复现的证据损失**，新增实体信号
   放大了这些既有规则，而不是单纯把更多正确候选交给重排。

本轮在 `fdc91a0` 工作树只读本地索引，复用 §4.9 已保存的48次真实重排分数；
不新增模型请求，不运行 ingest/OCR，不改算法、索引或运行配置。所有反事实为独立进程
临时 monkeypatch 或产物回放。排序反事实基准逐题复现原有 top-5 后再改变单一因素。
新增候选或新窗口没有经过真实重排，不能从其覆盖率推断模型排序一定改善。

## 2. 先纠正评测：存在的字面值不等于问题的答案

### 2.1 已由原始 PDF 确认的标错

- **A08** 问 QMI8658A/B 与 ICM-42605 的陀螺仪量程。QMI 标注却指向 RevD 第22/19页，
  内容是 Host SPI/I2C/I3C Interface Speed（15 MHz、400 kHz、12.5 MHz）。
  原 PDF 这些页没有陀螺仪量程表。
  量程实际可见于 QMI8658A 第18/31页、QMI8658B 第15/27页及各自首页，
  涉及 ±16 至 ±2048 dps。默认重排 A08 已把 QMI8658A 真正含量程的第18页排进 top-5，
  旧标注仍判为未命中。
- **A03** 问负载调整率，其中 AMS1117-3.3S 标注为第4页的 `3.300`，条件为10mA、5V、25°C。
  本地 MuPDF `find_tables()` 直接提取的对应行是输出电压 `3.234 / 3.300 / 3.366 V`；
  负载调整率是另一行 `Rload`，典型/最大 `10 / 18 mV`。

因此 `--validate-only` 只能确认文件、页、字面值、型号一致，**不能确认参数/条件/列的语义**。
“全部标注可核验”的表述应理解为字面存在性，不是标注正确性。全32题需要逐目标人工语义审校，
不能仅靠当前校验器作为上线门槛。

### 2.2 内容别名与型号身份不能混成一个指标

MX25R 四个订购料号文件的 PDF MD5 相同。B06 只认其中一个文件名，D04 还把其中两份
完全相同的字节副本列为 forbidden variant。对同一证据内容的正确去重会被旧指标计错。

建议拆分：

- **内容证据覆盖**：字节一致副本可共享内容身份，但须保留原始来源别名与引用。
- **料号身份确认**：另检查订购表/主体是否真的包含所问料号；不能因内容相同自动断言兼容。
- **指定来源约束**：用户明确厂商/版本时，必须保留对应来源，不用“同型号”替换。

### 2.3 去掉已确认错题后，退化仍存在

不新增模型请求，只从两遍真实分数回放中剔除 A08，剩余7题：

| 指标（FTS+真实重排 / top-5） | 默认 | 第一阶段实体桥 | 升级版 |
|---|---:|---:|---:|
| 全部目标页齐全 | 28.6% | 28.6% | 14.3% |
| 平均目标召回 | 57.1% | 47.6% | 42.9% |
| 文件/页/条件片段覆盖 | 52.4% | 42.9% | 33.3% |

两遍一致。这仅说明“剔除这个已确认错题后，先前差距并未消失”，不是对剩余所有目标
已完成语义审校的保证。原8题与32题历史分数保留，但不再作为已校准的准确率基线。

## 3. 来源去重把小幅加分放大成整份证据删除

相关实现：`backend/retrieval.py` 的 `_same_document`、`_pick_latest`；
`backend/doc_utils.py` 的 `title_key`、`block_sim`。

### 3.1 真实复现

| 案例 | MD5相同 | 标题指纹相同 | 触发合并的最大块相似度 | 当前阈值 |
|---|---|---|---:|---:|
| B01 XC6206 Torex / UMW | 否 | 否 | 0.46679 | 0.4 |
| C01 74LVC1G04GW 两来源 | 否 | 否 | 0.41737 | 0.4 |
| D02 AO4407 两来源 | 否 | 否 | 约0.462 | 0.4 |

规则是：同型号且**任意一对命中代表块**足够相似，就把两份文件作为同文档。
元器件数据手册同型号的特点、表头和参数描述本来就相似；局部 bigram 相似不能证明
同厂商、同文档或版本继承。标题相等分支也没有额外厂商/文档类型保障。

B01 两份文件都无版本，赢家改由该文件的**最高融合页分**决定：

- 默认：Torex `0.03205128`，UMW `0.03125763`，保留 Torex。
- 实体桥后：Torex `0.03838040`，UMW `0.03840049`，保留 UMW。

实体桥没有为 B01 新增任何页面，只给已有26页加分，约 `0.00002009` 的赢家分差就删除了
Torex 整份候选，包括3个已召回目标页。重排的身份行已经写明 UMW，但它根本看不到 Torex，
无法修复这次来源删除。

### 3.2 32题逐层追踪（80个标注目标，重复页目标分别计）

| 层级 | 默认 | 升级版 |
|---|---:|---:|
| FTS已召回 | 65 | 65 |
| FTS+型号子串 | 71 | 71 |
| 加实体通道后 | — | 77 |
| 进入截断候选池 | 66 | 72 |
| 去重后精确文件目标仍在 | 59 | 62 |

升级版的10个去重损失中，7个是不同字节的来源被压掉，3个涉及字节相同别名。
默认分别为4个和3个。实体桥并非没补到候选，而是补召回后又被既有决策丢掉。

离线消融结果：

- 仅对相同MD5去重，升级版精确文件目标保留从62增至69。
- 保留原去重但不给已有页再次加实体分，B01三个Torex目标重新保住；总目标数仍62，
  说明这不是可直接上线的全面收益，而是对相互作用的因果验证。
- 不去重时72个目标均在池里，但字节副本会浪费候选，故“不去重”也不是正确终局。

**优先修法**：内容MD5去重和文档版本合并分离；非同字节版本合并必须要求显式文档族、
厂商、类型及版本继承证据。无把握时并列候选，不能仅凭型号+一对文本相似度删除。
实体通道优先补缺页/缺块，不应让重复身份信号支配整文件来源选择。

## 4. 页面角色惩罚覆盖了模型判断

相关实现：`retrieval._role_penalty`、`_rerank_and_order`。
重排最终排序不是纯模型分，而是 `relevance_score × role_penalty`。
首页一律乘0.9，目录/修订史页乘0.75。

已确认的有效目标 D01：UMW XC6206 首页有静态偏置电流与输出能力，原始真实重排分
`0.9713038` 为第1；乘0.9后为 `0.87417342`，变成第9，证据被挤出前5。
A08 的 ICM 首页原始第1–2也因此降到第12–26，但 A08 其余目标已标错，不能拿整题分数
直接说明算法收益。

只回放已记录分数、关闭角色惩罚，剔除A08的7题两遍一致：

| 指标 | 默认当前 | 默认无角色惩罚 | 升级当前 | 升级无角色惩罚 |
|---|---:|---:|---:|---:|
| 全目标页齐全 | 28.6% | 42.9% | 14.3% | 28.6% |
| 平均目标召回 | 57.1% | 64.3% | 42.9% | 50.0% |
| 条件片段覆盖 | 52.4% | 59.5% | 33.3% | 40.5% |

改善来自D01，不依赖错题。不是建议盲目全局关惩罚：历史基线要重测；更合理的是按实际
页面角色确认再惩罚，或让强模型相关性与明确参数证据免于“物理第1页=封面”的假设。

## 5. 两窗对齐解决了“一致性”，没有保证“充分性”

相关实现：`backend/evidence.py::select` 与 `retrieval.snippet_reference/_score_window`。

1. 先为各块找900字符窗口并评分。
2. 选两个文本不完全相同的块，不评估第二块新增的查询信息。
3. 预算重新分成每窗约449字符，再各自重新定位，窗口位置可漂移。
4. 超限在字符处截断，不保证参数行和条件完整；表头也占同一预算。

以32题已召回目标对应的77个标注目标作离线覆盖分析（这些标注未全部语义审校）：
单窗900含完整字面值与条件64个，当前双窗60个；损失5个、收益1个。
A01 AMS1117与XBL1117目标页在900字窗内可完整容纳，均分后丢掉档位、数值或条件；
同页第二块没有补回缺失事实。B05的I2C页还同时选择了原生文本与其Markdown转储，
它们并非两个独立条件事实。

**优先修法**：保证一条完整的参数/条件证据为主窗口，第二窗必须有可证明的信息增益；
按完整行/表头及条件边界自适应分预算，不能默认50/50。重排与展示仍共享相同证据包，
但“共用证据”不应反过来强制使用不充分的窗口。新窗口需另行获授权请求真实重排验证，
本轮不从旧分数外推其模型表现。

## 6. 身份、数值、参数在各通道的词法不统一

### 6.1 完整料号拆分泄漏

实体 `_model_tokens` 为多型号文档拆连字符时，只要求两侧各含字母和数字。
因此 `SSP1117-3.3V` 被拆成完整料号、`SSP1117` 和 `3.3V`；`AMS1117-3.3S` 同样产生
`AMS1117` 与 `3.3S`。这些部分被写进实体反向索引，不只是查询临时误判。

C05本来只问SSP1117，实体候选却分配给 `model:3.3v / model:ssp1117 / model:ssp1117-3.3v`
三个组，实际纳入AMS1117与LM1117的3.3V器件；D05同样越到不同后缀手册。

多型号名单的拆分必须以明确的料号词法/已有身份字典确认，数值后缀不拆；
“含字母数字”不足以作为完整独立料号证据。

### 6.2 子串与窗口算法仍使用旧token

- 旧 `_model_tokens` 只取连续字母数字，`ICM-42605-HXY` 没有任一段同时含字母数字，
  不进入型号子串召回。
- `_query_terms` 保留连字符/小数点整体，因此完整型号不在旧排除集合内，仍参与页内打分。
  文档写“型号不参与窗口”是设计意图，但当前对带标点型号不成立。
- `_NUM_UNIT_RE` 缺少边界，`74LVC1G04GW` 内的 `1G`、`SSP1117-3.3V` 的 `3.3V` 都能
  给页眉固定参数值加分，进一步偏向身份文字。
- 子串按Arrow扫描顺序取前limit个块，而不是查询参数相关性；过滤在截断后兜底。
  结构化新增通道虽做过滤预算，旧通道的这个边界没有统一。

**优先修法**：共享一个确定性查询解析结果，分别提供料号身份、参数符号、单位值与
真正的页内内容词；每条通道复用，类型之间不互相退化。正文不推断写回 `model_no`。

### 6.3 白名单覆盖不足时，扩展实际成为“型号前几页”

32题中12题没有任何非型号/数值的实体信号，包含陀螺仪量程、压差、负载调整率、
绝对最大额定值、订货标记等。A08只剩三个型号，实体 `order()` 对同身份页没有内容差异，
最终按文件/页码稳定排序。40页直召额度分给每个型号约13页，QMI8658A RevD目标相关页
未必入选，甚至被同型号另一份文件抢走。

候选截断也会再丢掉本已召回的页；配额只保证型号代表性，不保证每型号的不同子问题齐全。
修法不是无限扩实体词表：无可靠参数信号时保守回退原召回/内容词，不沿同型号泛扩；
复杂查询分解成有限“型号×参数/条件”证据槽，配额约束证据覆盖，而不是仅按型号轮转。

## 7. 需要明确排除的错误解释

- **不是上游故障**：48次真实重排全部成功、无降级；分数抖动约0.004，质量结论两遍一致。
- **不是OCR没提到**：已定位的关键目标原文/表格存在；本轮未请求OCR，不能把缺候选归因给OCR。
- **不能全怪最终配额**：已有真实分数去掉最终型号轮转，8题两遍核心覆盖指标不变。
  配额改变顺序和名额，但该样本的退化另有候选/去重/窗口前因。
- **不能宣称关掉去重/惩罚就全面提升**：只对相同候选、相同文本回放分数的惩罚消融可直接比较；
  改候选/改文本后缺少对应真实分数，必须重新实测。
- **当前不是关系推理引擎**：实体桥主要做共享型号/符号的一跳补候选，没有事实条件约束和
  子问题覆盖规划；不应根据SAG官方开放域多跳问答指标预设这里有效。

## 8. 推荐修复顺序和验收门槛

1. **P0：评测语义与内容/身份别名校准**。先修A03/A08/D04并逐目标审校其余题；保留旧版，
   新版增加参数名/单位/条件来源范围、可接受等价证据页和内容身份。
2. **P0：来源保全与去重边界**。相同MD5内容去重仍保留所有来源身份；不同内容的版本合并
   必须有明确文档族。验证Torex/UMW、74LVC1G04GW、AO4407不再因通用描述被删除。
3. **P1：统一查询词法**。完整料号后缀不拆，单位不成型号，符号不成料号，页眉不拿数值加分。
   专测1117-3.3V、ICM-42605-HXY、74LVC1G04GW、Vdif1/2。
4. **P1：完整主证据窗与角色惩罚**。保留行/条件整体与主窗，第二窗检查信息增益；
   用现有分数单独验证角色启发式，修改窗口后再独立测模型。
5. **P2：证据槽/覆盖感知候选组织**。先保证每个型号与子参数都有可读证据，再让重排
   做组内选择；不继续把文本共识分与模型分任意融合。

所有改动继续在实验分支、默认关闭。先关键回归和固定本地对照，再做小规模真实重排重复验证；
每项改动独立评估，不能把调过的同一批题当作无偏泛化测试。生产部署、索引重建与新增模型
调用均需各自授权，本轮只提交调研结论。
