## 文档维护约定

- 设计边界放在架构文档，具体部署命令放在部署文档，历史实验数字放在实验记录。
- 实验记录注明环境、样本范围和是否调用模型；离线替身验证不得写成端到端质量保证。
- 链接使用相对于当前文档的路径，新增或移动文档后检查引用。
- `DEPLOY-NAS.md` 等含内部地址、账号或主机路径的运维记录只留在本机，已被
  `.gitignore` 排除，不进入当前源码或发布包。
- `.env` 只保存本机配置和密钥；`.env.example` 只能保留示例值。密钥、运行数据、
  PDF 语料与索引均不提交。发布取源码时以 `git archive HEAD` 为准。
