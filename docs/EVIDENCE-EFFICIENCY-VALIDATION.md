# 证据效率逐项验证（2026-11-01）

## 方法与冻结边界

起点 `c640ece`，实验仍在 `feat/sag-entity-bridge-20261031`。本轮验证来源约束、
参数/条件/数值角色绑定、缺失证据补查和紧凑分层输出，不引入完整 SAG 引擎。
所有实验只读同一现有索引，禁止 socket 网络，不请求 embedding/rerank/OCR，不 ingest。
原型不接入生产 API，不改变现有搜索默认行为。

`eval_evidence_efficiency.json` 固定20道新参数/来源/负例/多参数题，17个页证据目标。
SHA256：`a4fa67c3cb778242ee5f61f8017e86a0b6c7322cd59eb1c9bf3f19ad95628adb`。
题目在修改原型前冻结，没有按检索预测筛题；仍是同库且由本会话审校的新意图集，
不是独立人员编写的无偏留出集。块锚点校验仅证明文字存在，不自动证明参数行列正确。
后续若改冻结题，必须另立数据版本并重新声明比较范围。

输入 `model/source_terms/revision/needs` 是显式任务约束，不从评测真值注入来源文件、
页、uid或答案数值。基线问题文字也包含这些条件；原型使用结构化输入，不能混称
纯自然语言自动解析效果，解析器成本和错误本轮未覆盖。

## 计量

- 页和片段覆盖：必须指定文件和物理页，且含审校所需字面值，非最终回答准确率。
- 来源负例：不存在的来源/版本及未指定而歧义的来源不得默默回退。
- 表行绑定：参数、显式条件和数值角色必须由同一完整行提供；全局条件/脚注另保留，
  只返回“行证据”，不声称条件完整适用。
- 上下文：同时记录响应UTF-8字节、字符、确定性词法单元代理；**不等于模型token**。
  任务链代理为每次决策重新携带此前工具响应的前缀累计字节，固定策略模拟，不是真实Agent。
- 不安装/联网下载分词器；本地没有目标模型tokenizer，实际token与账单结论留空。

## 修原型前基线

`tools/eval_evidence_efficiency.py` 默认走现有 structured FTS/无重排，两轮独立进程：

| 指标 | 结果 |
|---|---:|
| 证据页覆盖 | 15/17（88.2%） |
| 参数/条件字面片段覆盖 | 12/17（70.6%） |
| 正例全页齐全 | 12题 |
| 工具调用 | 20 |
| 响应总字节 | 227703 |
| 降级 | 0 |

此基线不会自动拒绝负例或绑定表格角色，不能把“有返回结果”计作成功。
它也尚未补读整页，后续紧凑输出须与同等证据完整度的流程比较，而不能只比较短响应。

