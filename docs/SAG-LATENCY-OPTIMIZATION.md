# 结构化检索延迟优化（2026-11-01）

## 方法与边界

起点`a6b9024`，同一只读本地索引（8561块）与进程环境，FTS/无重排。
结果缓存关闭；实体索引和投影/FTS预热后测热查询，实体冷建另测3次。
关系集27有效题与旧55题各跑两轮，第二轮反向查询/默认与结构化顺序，避免把固定顺序当收益。
profile仅定位热点，不使用其受插桩影响的耗时作正式延迟；真实模型不调用。

优化要求：默认与结构化结果、排序、片段、引用、事实与候选诊断（除时间/缓存字段）相同；
27题确定性重排替身的输入哈希和结果也必须相同。不得缩候选/窗口、删条件、关校验来追求性能。
不部署、不索引、不改运行配置/依赖，不启动子代理。性能为本机逻辑开销，不是NAS线上承诺。

## 第一阶段：请求内去重复计算

27复杂题热profile共4.04秒，`extract_entities`累计2.76秒、调用13069次，
`_cover_evidence`两轮分配累计2.26秒，占总profile约56%；证据窗口选择另占1.02秒。
同页重复命中块、排序前后覆盖分配和每页查询解析做了重复工作。

修法：
- 用单次查询的`_EvidenceCoverage`复用页/相同正文块实体与型号解析，不跨请求缓存正文。
- 查询词与查询实体解析结果供同次候选窗口复用，窗口/增益计算规则不变。
- 结构化结果不再先生成随后被证据包覆盖的默认窗口/引用。

| 同机热态，结果缓存关闭 | 优化前 | 请求内复用 |
|---|---:|---:|
| 27题p50 | 112.70ms | 70.94ms |
| 27题p95 | 179.03ms | 115.67ms |
| 旧55题p50 | 31.59ms | 27.17ms |
| 旧55题p95 | 382.71ms | 133.67ms |

两轮82题默认/结构化输出快照无差异，27题重排输入及替身结果完全相同；304项后端测试通过。
profile实体解析调用13069→6037，累计CPU热点下降；实体冷建中位仍约3秒，尚未改善。

## 第二阶段：只在使用时生成证据窗口

`evidence.Bundles`为每次请求建立惰性字典，读取某页时才生成其窗口，之后在本次请求复用。
开启窗口重排仍逐项读取全池，生成的模型输入不变；无重排只取实际返回页。整块重排不预先生成
窗口，但内容感知角色惩罚仍会按需读取全部参与排序页，不能宣称该路径只计算展示页。
保留默认窗口算法、证据预算与fallback，不改变候选排序。

两轮同机关系题p50/p95为53.49/95.25ms，旧55题为13.04/117.06ms。
与最初基线相比，82题默认/结构化快照与27题重排正文/替身结果仍完全相同。
305项后端测试通过。第一次全套因`/tmp`满导致向量索引临时文件写入失败；未删除已有数据，
改用独立磁盘`TMPDIR`重跑后全部通过。该项不减少真实重排等待时间，不能把无重排收益外推为线上总耗时同比下降。

## 第三阶段：仔细改写热点正则

逐段计时发现接口/符号正则在整个正文的每个位置反复尝试相同首字母的多个分支。
采用公共前缀因式分解（如`v(?:...|...)`、`u(?:sart|art|sb)`），并把互不重叠的接口/符号
合并为一次扫描。保留原`re.I`的Unicode语义和ASCII字符边界；不以`re.ASCII`偷换召回范围。
英文参数别名用一次`[a-z0-9]+`词集合预筛，再跑原始完整别名正则；中文别名仍按原字面匹配。

`VALUE_RE`只对数字与空白使用占有量词`\d++/\s*+`。它们与后续单位首字符不相交，
不需要退回更短数字/空白；单位分支、可选小数整体和符号分支不盲目atomic化。
查询型号/主表身份规则不变，不新增参数别名、不修正数值语义。

- 接口+符号子步骤：全库三次中位1551ms→前缀分组902ms→合并扫描822ms。
- 数值匹配子步骤：260→222ms；2万位数字但无单位的失败样本约1.25→0.17ms。
- 符号空白量词改成占有型真实语料几乎无收益（991→986ms），未为其引入额外复杂度。
- 未发现所测有界长失败样本呈灾难性回溯；收益来自少扫/少尝试，不以ReDoS修复宣传。

8561块正文在有/无model_no下完整实体输出均与起点一致；2.5万组匹配span/文字边界组合、
另1万组完整实体与截断规则等价。测试覆盖长数字/空白、混合型号、重叠词、Unicode I/S、
单位大小写、连字符与括号。真实语料等价不代表所有未来输入自动保证，关键边界已回归。

## 最终独立复测

同机两次独立进程，每次27关系题和55旧题各两轮，结果缓存关闭。与起点比较：

| 本地逻辑口径 | 优化前 | 优化后独立进程1 / 2 |
|---|---:|---:|
| 实体冷建中位（每进程3次） | 3033ms | 2058 / 2047ms |
| 关系题，结构化无重排p50 | 112.70ms | 41.75 / 41.63ms |
| 关系题，结构化无重排p95 | 179.03ms | 82.08 / 78.63ms |
| 旧55题，结构化无重排p50 | 31.59ms | 12.14 / 12.61ms |
| 旧55题，结构化无重排p95 | 382.71ms | 94.98 / 96.69ms |

关系题热中位降低约63%，冷建降低约32%。旧55题的长尾收益较大，但样本/缓存/调度仍会影响p95，
不能据此承诺NAS或任意数据规模同幅提升。默认无结构化关系题约10.6–10.8ms，未增加实体构建。

为避免只报无重排路径，使用相同提交基线模块与确定性重排替身另做两轮对照：

| 27关系题，结构化 | 优化前p50/p95 | 优化后p50/p95 |
|---|---:|---:|
| 窗口重排替身 | 124.75 / 186.08ms | 65.64 / 101.15ms |
| 整块重排替身 | 124.36 / 187.77ms | 64.15 / 100.43ms |

这只计本地成本，不含真实模型网络与推理；约省59ms逻辑开销不等于线上总延迟减半。
未以减少或增加候选/重排文本改变模型成本；本轮也没有重新测真实模型效果或token。
无重排82题×默认/结构化，窗口/整块重排各82题×默认/结构化的结果和重排输入哈希均与基线相同。
空证据包仍保留旧snippet_ref fallback，不用正常语料未覆盖的边界换取收益。
309项后端测试、文档及diff检查通过；首轮TMPDIR满盘失败与独立磁盘重跑记录均保留。

## 否定性实验与后续选择

对参数别名合并成一个大触发正则，8561块输出等价，但该子步骤中位约928→1031ms，
慢约11%，未采用。单次ASCII单词集合预筛约930→747ms，约快20%，已在完整等价对照后采用；
不能把子步骤比例当整体冷建提升比例。

未引入跨请求全文LRU、常驻全文副本、缩候选池、关校验、后台模型探测或生产自动预热。
冷建约2秒仍存在。下一步若需隐藏首次等待，可另行评估受控本地预热；多worker会各付冷建和
内存成本，不能默认无限加进程。持久化实体索引会引入版本/文本一致性与存储契约，本轮不做。
本机`/tmp`为满盘状态，未清理未知/唯一实验产物；测试仅通过独立磁盘TMPDIR运行。
